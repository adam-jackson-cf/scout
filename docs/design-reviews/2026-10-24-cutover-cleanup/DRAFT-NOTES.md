## Judgement calls for the council

The twelve calls are in `PROPOSAL.md` ("Judgement calls for the council"); the ones most likely to change the text:

1. **1B over 1C.** The v1 re-anchor stays because §3.3, Phase 1, R1 and REQ-10 mandate it; dropping it needs a fact only the user has (does any v1 `.scout` bundle exist?). Assumption A13 carries it.
2. **Refusing 1, 2 and 4–11** rests on the tags and git history (`schemaVersion` is 12 in every tag; Phase 1 introduced 4–5 on 2026-10-23 before v0.1.0), not on a survey of machines.
3. **2B at `LoadBase` only** (so `state restore` and `state publish` still work and heal the branch; import records no comparison identifiers from a manifest without the field); the cost is exit 3 on PR runs against a manifest without `uninspected` (a v0.1.0/v0.1.1 publish, or an earlier build's publish with no finalized run and no imported lane health) until the next default-branch publish. No such manifest was observed (17 of 17 carry the field).
4. **`claude` then `codex`** for the one order (leaves `Detect`, the matrix and `Plan.ModelDigest` unchanged); `CLAWPATCH_PROVIDER` ignored, not rejected (it is Clawpatch's own variable).
5. **4E**: delete the composite action and share two scripts of the release tag. `$/` was rejected because GitHub documents it as unavailable on GitHub Enterprise Server and it resolves at the workflow's commit, not at `scout-version`; `owner/repo@ref` needs a literal owner and ref (`uses:` takes no expression); checking the workflow's own repository out at `job.workflow_sha` and using `./…` (4G) is rejected because the checkout lands in the assessed workspace, runs the workflow's commit rather than `scout-version`, and `job.workflow_*` is unavailable on GHES. The adopter-facing entry point is lost (tags keep it); adopters are unobserved. Script names are proposals.
6. **R17, A13 and the §10.2 rows** are added content the user did not ask for; they record consequences and assumptions and add no mechanism.
7. **Code cites.** Cites in `PROPOSAL.md` to `internal/**`, `cmd/**`, `.github/**` and `scripts/**` are file:line as read on 2026-10-24 while sibling sessions edit those trees (line numbers drift by a few lines); the design text cites symbols and files, not lines, for the new content.
