No new mechanism.
2. **Reading "exit 3 naming the minimum tag" into the PROPOSAL inventory.** Issue 6 specifies the behaviour in the design text; the PROPOSAL inventory states where it lives (a check in each workflow after the clone that both scripts exist), because the scripts cannot fail from a tag that lacks them.
3. **4E's "works on GitHub Enterprise Server"** was reworded (not named in the issues) because it contradicted the corrected 4D/GHES position.
4. **§10.2 row 352** now names the `Store.Import`/export rule so the inventory delivers the issue-2 behaviour.
5. **Stale session remarks** (`another session's file`, `shared file … after the other session's change lands`, `sha256.sh uncommitted`) were removed or reworded; `2710447` has landed and `scripts/sha256.sh` is committed at HEAD.
6. **R-045 row** wording extended to cite the contexts reference for `uses:` taking no expression and for `job.workflow_*` unavailability on GHES, as the council instructed; this rests on the council's reading of those pages and was not re-fetched here (no model calls, no web access used).
