## Route change and simplification

ADR-011 is now a separate canonical PR/worktree (`scout-adr11b`, base d2479d54), landing first with R-064/static R-069. ADR-012 remains canonical in `scout-adr11`, with its ADR-011 folder/card/index/reference/ledger/trackers removed. Historical combined rounds and round-1-response stay byte-identical as historical records. **Rebases onto ADR-011 once merged**, followed by review of final resolved canonical bytes. No ADOPTION.patch/result-hash artifact, prescribed parent, virtual revision, no-squash rule or X1-after-both constraint remains. Ordinary independent PR adoption on each zero-issue final round replaces those requirements.

Select Main's recommended simplification rather than retain the council's PR-produced-artifact recipe: one protected-default-branch workflow owns intent registration, isolated measurement and trusted finalization. Its scan is a separate credential-free network-denied job, never privileged PR execution. The protected source and literal release pin produce the facts themselves. Existing guardian PR jobs remain outside the readiness trust path.

Cuts and reasons:

- **Cut arbitrary PR-workflow collection, caller-file gates, script/local-action dependency tracing and resolved PR-callee authentication:** PR workflows produce no accepted readiness facts. The fixed protected workflow's own source/release/job identities are registered instead.
- **Cut PR-cache verification and workflow-directory refusal:** the isolated shadow scanner has no shared cache, and other workflow files are ordinary data. Action-ref/Dependabot changes remain measurable.
- **Cut fork run→PR inference and synthetic merge recovery:** registration takes the protected event's validated PR key and resolves actual head/tree/base objects directly; no synthetic merge input.
- **Cut retention-derived waits/API and general provider-history reconstruction:** durable intent precedes every scan; reconcile only registered/configured protected workflow runs. A one-hour completion grace handles missing output; stale/expired collection evidence is a gap. No retention settings lookup.
- **Cut modifications to existing reusable callers' permission ceilings:** a new opt-in caller explicitly grants the separate shadow workflow its permissions. Missing opt-in is unmeasured, not a guessed producer.
- **Keep internal bounded output transport, failed-writer reconciliation, event links and all intervals/gaps:** these remain necessary to move facts between isolated jobs, retain zero-event attempts, prevent disappeared denominators, preserve triage, and reproduce activation dossiers. Internal artifacts are generated only by trusted template code, not imported from PR-controlled jobs.
