# Guidance

## When to record

- Add or update a row in the hypothesis ledger named in the project's agent instructions when a hypothesis is proposed, preregistered, put under test, given a result, revised or withdrawn.
- Every change also gets a dated History line.

## Entry template

- Register row: `| H<n> | <one testable sentence> | <R-IDs> | <state> | <experiment IDs> | <effect with 95% interval, or —> | <YYYY-MM-DD> |`
- History line: `- <YYYY-MM-DD> — <ID>: <state change and reason> (<R-ID or experiment>)`

## States

- Allowed states: `proposed`, `preregistered`, `under-test`, `supported`, `not-supported`, `refuted`, `inconclusive`, `revised` (link the new ID), `withdrawn`.
- Only an experiment signed off under the project's experiment rules may set `supported`, `not-supported` or `refuted`.

## Rules

- Every source cited must already exist in the research ledger named in the project's agent instructions.
- Outcomes state the effect and its interval, not only a verdict.
- Never delete a hypothesis; mark it `withdrawn` or `revised`.
