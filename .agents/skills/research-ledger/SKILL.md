# Guidance

## When to record

- Add a row the first time a source (paper, report, repo, docs, internal study or user direction) is used to justify an approach, a design choice or a hypothesis.
- Do not record sources that were read but not used.

## Entry template

- Append one row to the research ledger named in the project's agent instructions: `| R-NNN | <source title> | <URL or repo-relative path> | <paper|report|repo|docs|internal-study|user> | <YYYY-MM-DD> | <decision or H-IDs informed> | <claim used, with its numbers> | <main limitation> |`
- Use the next free `R-NNN`.

## Rules

- Append only: never edit or delete a row; correct an entry by adding a row that names the `R-NNN` it supersedes.
- The link must resolve; record user direction as type `user` with the conversation date.
- Cite `R-` IDs in experiment preregistrations and design changes.
- When the source forms a hypothesis, also record it in the hypothesis ledger named in the project's agent instructions.
