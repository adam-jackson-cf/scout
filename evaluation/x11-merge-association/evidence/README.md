# Preparation evidence

The preparation files in `artifacts/` (6,085 files, about 210 MB uncompressed). `artifacts/preparation-runtime/` (a Go build cache and lock slots, 184 MB) is left out because it is regenerated by the preparation driver are too large to keep in git. They are stored as a release asset, and `SHA256SUMS` in this directory records the SHA-256 of every file.

| Release | Asset | Size | Asset SHA-256 |
|---|---|---|---|
| [`evidence-x11a-preparation-2026-11-28`](https://github.com/adam-jackson-cf/scout/releases/tag/evidence-x11a-preparation-2026-11-28) | `x11a-artifacts.tar.gz` | 27473509 bytes | `4c3c378b1243b1632a8dd68595ce5a555b2ceb76bb657ec6cd8e52a0e92c383f` |

Restore and verify from the repository root:

```sh
cd evaluation/x11-merge-association
gh release download evidence-x11a-preparation-2026-11-28 -R adam-jackson-cf/scout -p x11a-artifacts.tar.gz
shasum -a 256 x11a-artifacts.tar.gz   # must match the asset SHA-256 above
tar -xzf x11a-artifacts.tar.gz
shasum -a 256 -c --quiet evidence/SHA256SUMS
```

The last command prints nothing and exits 0 when all 6085 files match. The extracted paths are ignored by git.
