2. **A missing `tool-versions` file or a probe not taken is inconsistent** (reason named), so an aborted collection cannot yield a citable arm.
3. **Issue 5:** the second option (text) was taken, but with the first `write_versions` moved into the protected block so the text is exactly true (previously a microsecond window left a versions file with no stop record). A `phase: setup` stop record was rejected because the append-only preflight would then refuse a rerun that lost nothing.
4. **Workspace config is recorded, not refused** (the before-probe precedes the clone); the optional `git ls-tree` check at the two pinned SHAs was not done in this study's preparation: the main agent can run it and state the result in RESULTS.
