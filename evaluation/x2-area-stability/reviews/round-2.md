**N2. The control gate (label validity) can pass without a single correct known answer, and its denominator contradicts §3.3.**
Location: `analysis.py:44-66` (`control_stats`), `common.py:54` (`LABELS` includes `cannot_tell`), `:48-50` (`wrong` = `same_concern` only for swapped, `different_concern` only for identical), `:58` (`if rows and …`: a kind with zero pairs passes); `build_pairs.py:114-139` (generation silently under-fills when no donor exists or a control collides; no minimum); prereg §4 gate 3 "labelled", §5, §6 "The controls bound anchoring"; `validate.py:343-357` (U checks use only same/different answers), `:53-56` (synthetic `entrypoints: []`, so the entrypoint swap at `build_pairs.py:72` is never exercised). The pooled gate (`analyze()` computes controls once, `analysis.py:324`, and passes the same object to both arms, `:350`) is reasonable for a *protocol* property but contradicts §2 "analysed … independently" and §4 "Arm B never changes arm A's verdict" as written.
