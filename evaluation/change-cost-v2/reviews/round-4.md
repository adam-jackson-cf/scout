## New issues

**1. Minor — exploratory statistics (S1, S2, P1_*) use the wrong cluster set for their jackknife.** `analysis.py:255` `cols = TEST_COLS.get(nme, CONTROLS + ["Q"])` for every name outside `TEST_COLS` (`:224-226`), so `present` (`:257-259`) ignores the statistic's own outcome/predictor columns (S1 needs `y_review`, S2 `y_rework`, P1 `D` and `y_active`; `:165-171,179`). A cluster with no rows in the statistic's complete-case sample counts as present; its replicate equals the full-sample value, inflating G/df and distorting the SE. This is concrete on the frozen panel: django has `y_active` set missing (repo rule, `build_panel.py:164-169`) but 29 areas (`constructs.json:341-344`), all counted for P1. Prereg l.120-121 fixes "G_t = the clusters present in test t's own complete-case sample" and l.141 says P1 uses "the same jackknife". *Fix:* add `S1: CONTROLS+["Q","y_review"]`, `S2: …"y_rework"`, and a P1 entry `CONTROLS+["Q","D","y_active"]` (lookup by prefix `P1_`) used only for `present`; keep the exploratory finite-filter. Test: synthetic panel with one repo's `y_active` all-NaN; assert P1 `df` excludes its clusters. Decision tests T1–T5 are unaffected.

**2. Minor — `analysis.logit` accepts a non-converged fit silently.** `analysis.py:104-114`: after 60 IRLS iterations the coefficient is returned whether or not `max|step| < 1e-8` was reached; the jackknife only checks finiteness (`:264-265`). A finite but unconverged T5 replicate would enter the decision SE unflagged, contrary to the prereg's "no silent dropping/hard error" policy (l.121). No evidence it occurs (harness/power checks all true), but it is undetectable as coded. *Fix:* raise `RuntimeError` when the loop exhausts without meeting the tolerance (decision test ⇒ hard error, as for non-finite replicates); test with `iters=1` on a synthetic sample. Re-run harness and power to confirm no trigger (results must reproduce apart from timing; if it triggers, that is a finding for round 5, not a deviation to paper over).

**3. Nit — stale check count.** `DESIGN-NOTES.md:12` "55 software tests" vs §8 `:106` "59 checks pass" and the main-agent run. *Fix:* 59.

**4. Nit — stale `validate.py` docstring.** `:5` says `RUBRIC.txt`; code writes `RUBRIC.json` (`:84`). `:16-17` still describes G7 precision over "pairs"; metrics are partner-level (`:228-231`). *Fix:* align the text (same class as round-3 #4).
