## New issues
**1. Must-fix — G7 blinded items reveal the proxy decision through their structure.** `validate.py:142` gives every *explained* item exactly one pair (`[pt["via_ref"]]`) and every *hidden* item 1–3 pairs (`rng.sample(pt["vias"], min(3, …))`); `:144-152` writes `pairs` unchanged into `dep-blinded.jsonl`, and `annotate.prompt` (`annotate.py:31-32`) sends the whole item. Any item with ≥ 2 pairs is therefore certainly proxy-hidden, contradicting prereg §5 ("blinded files carry no … stratum") and the round-1 blinding standard. *Fix:* make G7 items pair-level: `sample()` emits one item per (via, partner) pair with opaque ids assigned after a global shuffle (explained → the `via_ref` pair; hidden → each of ≤ 3 seeded vias), keeping `partner_key` only in the unblinded sample file; `gates()` aggregates per partner (hidden partner = `no` iff every decided pair is `no`, `cannot_tell`/unresolved if any pair is, κ on pair-level labels), then applies the unchanged thresholds and reports partner-level `cell_sizes`. Prereg §5 G7 sentence "G7 shows the pair that decided the proxy" rewritten accordingly; extend the `tests.py` G7 fixture with a multi-pair hidden partner (mixed yes/no → `yes`).

**2. Minor — G7's per-language rule silently skips a language with no decided hidden item.** `validate.py:225` builds `by_lang` from `hid` (decided hidden items only); `:232` checks only those groups. If all 12 hidden items of one language are `cannot_tell`/unresolved (10 % of 120 < 15 % cap), the language vanishes and G7 can pass, contradicting prereg §5 "in every language group". *Fix:* iterate over `{rows[i]["lang"] for i in rows if rows[i]["proxy"] == "hidden"}`; a group with `n == 0` decided items sets `hidden_precision = None` and fails the gate; add a test.

**3. Minor — G1 exclusion is not mechanical.** Prereg §5 G1: "else the repository is excluded", but `gates.py:29-30` only reports `pass_`; `build_panel.py:148-156` gates on n/variance/areas/floor only and `analysis.main` never reads `G1`. All 16 repositories pass today (axum lowest, 94.8 %), so the frozen panel is unaffected, but it is the same human-set pattern removed in rounds 1–2. *Fix:* `build_panel.py` computes snapshot coverage from the per-repo skip counts (same formula as `gates.py`) and includes `coverage ≥ 0.85` in `gate[repo]["pass"]` (recorded in `repo-gate.json`); `gates.py` keeps reporting; test with a failing fixture. Panel content unchanged.

**4. Minor — stale usage lines in frozen scripts.** `analysis.py:5` omits the now-required `--gates` (the command fails as written); `harness.py:6` advertises `[sims] [B] [out.json]` while `main()` takes `[sims] [out.json]`. Prereg §10 commands are correct. *Fix:* correct both docstrings.
