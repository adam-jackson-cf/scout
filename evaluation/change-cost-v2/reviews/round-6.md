## New issues (all count under the zero-issues rule)

**1. Minor — identical `unparsable` answers count as agreement in κ, and are never adjudicated.** `PREREGISTRATION.md:149` "C labels only items where A and B disagree … an unparsable answer is a disagreement"; `:168` "An `unparsable` annotator answer is a disagreement (consensus `None`, counted as unresolved)". Code: `validate.kappa` (`validate.py:163-168`) computes `po = Σ[x == y]/n` and `pe` over all categories, so an item where A and B both return `unparsable` is an **agreement** and `unparsable` enters the expected-agreement marginals; `gates()` feeds raw labels to it for G4/G5/G7 (`:195,207,223`). `annotate.py:72` `dis = [... if lab A != lab B]` never sends such items to C, and `consensus()` (`:176-180`) returns `None` for them even if C had labelled them. `tests.py:311-312,329` build exactly this case (T010/T011, D004) but assert only the unresolved share, not κ. Round 2 (minor 4) fixed consensus only; κ was never checked. Impact: `unparsable` is also the result of three failed HTTP attempts (`annotate.py:57-59`), so a correlated endpoint failure makes A and B "agree" on up to the 10 %/15 % unresolved cap and inflates κ(A,B) toward the 0.5/0.6 gate thresholds — anti-conservative for gate admission. *Required fix:* (i) `kappa`: an item with either label `unparsable` never counts as agreement and `unparsable` is excluded from the `pe` marginals (n unchanged); (ii) `annotate.py:72`: adjudicate items where A = B = `unparsable`; (iii) `consensus`: A when A = B and A ≠ `unparsable`, else C (so the C label is used); (iv) tests: κ value with identical `unparsable` pairs (e.g. κ unchanged vs. the same sample without them) and the both-unparsable → C path; update `tests.py:293`. If instead the prereg is amended ("identical `unparsable` answers are unresolved, not adjudicated, and excluded from κ"), say so explicitly in §5 and in the round-6 response. Either way: `tests.py` re-run, digests for `validate.py`, `annotate.py`, `tests.py` (and `PREREGISTRATION.md` if amended) recomputed. (Found by the challenger; verified.)
