## Issues

**1. Major — C-side transport failures are still recorded as `unparsable` labels, contradicting the amendment's own principle and made irreversible by the one-shot rule.**
Evidence: `annotate.py:60-71` — after three generic exceptions (`except Exception: pass`, i.e. timeouts, 5xx, 429, JSON errors) `call()` returns `label="unparsable", model_resolved=""`. `answer()` (`:43-52`) now aborts on truncation/empty content because "it is an infrastructure failure, not an answer", but the sibling infrastructure path is unchanged. `validate.consensus` (`:179-184`) turns that row into unresolved; AMENDMENT-1 §5 then forbids any further annotation rerun. Run 1 shows the failure class is real (95/95 C rows were infrastructure artefacts); the one-shot rule is new. Prior council acceptance of this path (round 10) predates both facts.
Required fix (either, both need round 12): (a) code — after the retry loop, `sys.exit` for every annotator instead of returning `unparsable`; add a `tests.py` check; or (b) amendment — pre-specify that `validate.py gates` runs only if `validation/annotations-C.jsonl` has exactly as many rows as A/B disagreements (95) and every row has non-empty `model_resolved`; otherwise the run is void (not the shot) and is restarted with unchanged scripts. (a) preferred: consistent with `answer()`.

**2. Minor — One-shot rule under-specified for aborted runs and for the `MAX_TOKENS` hint.**
Evidence: AMENDMENT-1 §5 "There is no further annotation rerun" does not say whether an aborted `--adjudicate` (truncation at 4096, model mismatch, HTTP 401/402) — which writes nothing (`annotate.py:96-99` write after both `list(ex.map(...))` complete) — consumes the shot. `annotate.py:51` prints "raise MAX_TOKENS", but changing `MAX_TOKENS` changes a frozen script digest (AGENTS.md rule 5).
Required fix: amendment states (i) an abort writes no `annotations-C.jsonl` and is not the shot; restart with byte-identical scripts is permitted and is reported under Deviations with its cause; (ii) any change to `MAX_TOKENS` or any script requires a new zero-issue round before running; (iii) the shot is the first completed `--adjudicate` followed by `validate.py gates` with `validate.py` f8643b2d… .
