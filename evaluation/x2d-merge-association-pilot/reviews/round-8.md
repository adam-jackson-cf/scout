## 2. Rulings

1. **The flake: closed as a verdict risk, not closed as a repeatable check (→ R8-02, minor).** The lead decomposed the six conjuncts of `validate.py:684-685` against `jev/main.go`: `r.returncode == 4` cannot vary (`stopped` precedes the failure exit, `:1026-1028`); `0 < n_after` cannot vary (the reply that crosses the cap is written before `cancel()`, `:997-1009`); `n_after < total` cannot vary (cap 5e-5 against > 120 requests); the `"budget"` text follows from exit 2 (`:878`). Only `stub.requests == before` is timing-dependent — and, as the experiment-peer showed, `spent1 > 0.00005` / `r2.returncode == 2` has a floating-point boundary (the driver sums cost in reply order, `:955-961`; `existing` sums the file in write order, so the two sums can differ by an ulp exactly when ΣL = 5000 for the states answered before the stop; prior negligible, `_stub_quiescent` inert against it). The addendum's mechanism is consistent with the code: `-workers 4` (`validate.py:528`); `cancel()` aborts up to three in-flight `client.Ask`; `wg.Wait()` waits for the client side only; the stub counts after `rfile.read` + `json.loads` (`stub_jev.py:88-91`), so a fully written body in the server's socket buffer can be counted after the driver exits, and `_send` already tolerates the resulting `BrokenPipeError` "(cost stop)"; r2 refuses at `:877-879`, before the client exists (`:928`). So the hypothesis is the only plausible nondeterministic conjunct, and the hardening is fail-safe (a stale `before` can only produce a false FAIL, never a false PASS; no planted-effect or planted-null check is involved — rule 4's substance is untouched). It is nonetheless not closed under the repeatability bar: (i) the 26 non-reproductions were of the **pre-hardening** check (the addendum's order: diagnosis → hypothesis → change), so the hardened check has one run; (ii) a handler descheduled across the 0.5 s settle still fails the check — the window is narrowed, not removed; (iii) the failing conjunct was never identified and the tuple cannot identify it on recurrence; (iv) a deterministic form exists at zero marginal cost — the driver writes `Endpoint` into the header (`main.go:855`) but does not compare it on resume (`:861-868`), so r2 pointed at a **fresh stub** reaches the budget refusal while a late request from r can only reach the first stub; `stub2.requests == 0` then needs no timing argument. Since R8-01 forces a round 9 in any case, the fix costs no extra round. Both peers reached this independently (challenger as major, peer as minor); the lead rules **minor**: no verdict, bar or gate is at risk, the failure mode is a false FAIL of the signing gate. Not a `Deviations` item: the change precedes sign-off and enters the frozen set through the round-9 digest list.
2. **R8-01 severity: minor.** The council's own R7-03 (c) text put two drafter-measured figures (61, 461) into §11 beside a sentence asserting none is there, and said "every other condition" where the code forces both e and h (`power_sim.py:199`; `README.md:64` has it right). The fix keeps the figures and makes the sentence true, rather than deleting them: the GO-share statement in the same clause is also a measured figure, so deletion alone would not restore the literal invariant.
