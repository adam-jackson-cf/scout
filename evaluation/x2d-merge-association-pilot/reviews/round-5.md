## 2. Rulings

### 2.1 N4b: a rule-4 failure, not a spend decision — the guard is replaced

**Ruling.** A guard that admits 0.255 false GO under a planted null is a failed planted-null check (rule 4). The drafter's routing to the round-0 `user_decision` mechanism is removed for null cells (R5-02); the guard is fixed (R5-01); every power cell is re-run.

**Mechanism (lead and both peers agree; the drafter's "noise" diagnosis is half right).** Under oracle self-abstention every resolved Jev answer is correct, so a = P_assign = R_assign_res = 1, b and i pass, e passes because `d_res ≥ 0` in every PR (`gain_res`'s bound is > 0 whenever ≥ 1 Jev-only cluster exists), f passes with ≈ 8 Jev-only clusters across 40 PRs. The verdict therefore rests on d (`gain_res ≥ 0.10`), g (the cap) and h alone. With counts a = Jev right ∧ B2 wrong, b = Jev wrong (abstained) ∧ B2 right, c = both wrong: `gain_res = a/(n − b − c)`, `gain_all = (a − b)/n`, `u = (b + c)/n`. At ρ 0.5 [INFERENCE, bivariate-normal integration, both peers independently]: E[`gain_res`] ≈ 0.109 / 0.089 / 0.075 at p 0.85 / 0.88 / 0.90, so d passes often; `a − b` is centred on 0 but **d and g select exactly the pilots with a high and b low**, so P(h | d, g) ≈ 0.85, not the marginal ≈ 0.45 (the drafter's own split: 255/297, 228/267, 141/161). The model reproduces the four measured cells (≈ 0.24 / 0.23 / 0.16 / ≈ 0). A point test on a mean-zero statistic is not a guard, and the council's Addendum arithmetic ("`gain_all` = 0.88 − 0.88 = 0 → fails h") held for the expectation only.

**Why no guard on `gain_all` can meet both bars at n ≈ 91 [INFERENCE].** Honest random abstention at u = 0.10 gives E[`gain_all`] = 0.95 · 0.90 − 0.80 = 0.055 against a per-pilot SE ≈ 0.052; the N4b null sits at 0 with SE ≈ 0.041–0.045. A 90 % one-sided bootstrap bound on `gain_all` (G1) would give N4b ≈ 0.06–0.10 (no margin against Monte-Carlo noise and a 40-PR percentile bootstrap) and P3-u10 ≈ 0.30–0.40 (bar 0.60 lost; P3-u05 ≈ 0.78–0.84). A point margin `gain_all ≥ 0.05` (G2) is calibrated to n = 91 and ρ 0.5, not to the live structure. A B2-accuracy-on-abstained vs resolved test (G3) is powerless at 5–13 abstentions and penalises an honest Jev whose abstentions track difficulty (B2 is weaker there too at ρ 0.5). And every `gain_all` test reinstates the "abstention = miss" accounting the user moved away from (R-051).

**The guard adopted (experiment-peer's G4; the lead's initial leaning was G1 and changed on this analysis).** The null the council means is "Jev's own answers are no more accurate than B2's; the resolved gain is selection". Selection moves *where* Jev abstains, never *what its answer would have been* — and that answer is already recorded for every V-sem row: `compose.py:72-74` writes `raw_covered` / `raw_choice`, the perception check (condition j) already defines the unthresholded combined answer (`analysis_x2d._jev_raw_combined`, `:611-615`), and `score_outcome` already carries both fields into every outcome (`:153`). The guard therefore scores an abstained cluster by Jev's own unthresholded guess: under oracle self-abstention that guess is wrong by construction, so the statistic equals `gain_all` and is centred on 0; under honest abstention it equals the raw edge (≈ 0.15) whatever u is, so the guard's honest cost is ≈ 0.01 and independent of u. The exact specification is R5-01. Expected operating characteristics [INFERENCE, to be measured]: N4b ≈ 0.03–0.05 at p 0.85, ≤ 0.03 at 0.88 / 0.90, ≈ 0 at 0.95; P3 ≈ 0.85 / 0.88 / 0.72–0.78; N4c ≈ 0.65–0.75. **No P3 bar moves.**

**Estimand statement (to be preregistered in §13, R5-03).** Under R-051's literal wording an oracle self-abstaining Jev with no accuracy edge is a selective-prediction success (100 % right on the 85 % it answers). Treating it as a null is the council's addition: Scout's design has no fallback rule for an unresolved merge association and X2d proposes no design change (`PREREGISTRATION.md:8`), so a GO must mean Jev's *answers* beat B2, not only that its abstentions are well placed. The guard fails → INCONCLUSIVE, never NO-GO, because such a Jev is not shown to be worse.
