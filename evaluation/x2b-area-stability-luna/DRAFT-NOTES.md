## Judgement calls for the council
1. **Reuse by import vs copy.** Everything but the collector is imported from frozen X2 and verified by SHA-256 pin before every stage and at collector start (a one-byte change fails closed). The collector is a copy because the argv/probe/arm choice are inline; its provenance is a committed unified diff (112 lines) that validation recomputes and requires equal. The alternative (copy all) would duplicate 3 000 lines and 1 600 lines of validation to re-justify; the alternative for the collector (runtime monkeypatching) was rejected as opaque. Consequence: X2b has no `common.py` of its own, `ARMS` in X2's `common.py` still lists claude; X2b's `write_transitions(arms=x2b.ARMS)` and the wrapper's unexpected-arm check keep claude out. X2's own validation is a precondition (check X).
2. **Combination rule (§4a)**: X2b alone decides; X2's codex result (adopt 0.30 on model option `default`, probe-served `gpt-6.1-sol`, effort not recorded — `low` in the user's config **[INFERENCE]**; pass set {0.30}) is a reported cross-check, never a rescue, veto or shift. Rationale: X2's mapper is not the one Scout ships (the user's R-040 direction). Round 1 judged this rule sound against three alternatives, now recorded in §4a: (a) **intersection** — `max(P_b ∩ P_X2)` degenerates to "0.30 or nothing" with P_X2 = {0.30}; (b) **minimum** `min(t*_X2, t*_b)` — can propose 0.30 when it fails C2/C3 in X2b and is the anti-conservative direction for spurious merges (round 1 corrected this note's earlier "conservative"); (c) X2 as a tie-breaker only when X2b is `inconclusive` — imports evidence from a model Scout does not ship exactly when the production evidence is uninformative. On `inconclusive`/not citable the default stays 0.5 and X2's 0.30 is **not** adopted — this is the sharpest consequence; the user's "set the default from X2 and that repeat" is read as "X2b decides, X2 is the reported cross-check" (§4a states this reading for the design round to check against R-040). The rule was written knowing X2's outcome (disclosed in the preregistration); the X2b data are unseen.
3. **One arm.** Costs stated in §4: no replication, no ABBA, no variance estimate, single draw per repository; the control gate is fed by one arm (≥ 226 unique pairs needed; X2's codex arm had 436; validation passes at 480 and fails at 180). Order codex/fastapi then codex/axum, fixed.
4. **Probe flags `--model`, not `-m`**, as `codex.ts` passes them (the brief said `-m`; Clawpatch's `addCodexModelArgs` uses `--model`, and the smoke shim confirmed `--model gpt-6-luna -c model_reasoning_effort="xhigh"`). The probe fails closed on a missing effort line; X2's probe did not record effort (its round-5 note called that optional).
5. **Citability extended** (served/flags check): recorded flags, Go configuration, per-map `agent-start` option `gpt-6-luna` (a failed map is exempt from the option check; a skipped map from all). The wrapper, not X2's `analysis.py`, applies it, so X2's `decision.citable` is overwritten (`and served ok and no unexpected arm`) — the only edit to a result field.
6. **Go-constant derivation is textual** (regex on `client.go`/`provider.go`), not a build; it checks `mapModel`, `mapReasoningEffort`, the exact `agentArgs = append(agentArgs, "--model", mapModel, "--reasoning-effort", mapReasoningEffort)` line, that `Map` calls `resolveMapProvider`, and that the resolver returns `ProviderCodex`/detects codex. A semantically different refactor that keeps those strings would pass; the Go test `TestAgentMapUsesCodexLunaXHighInHostAuthContextWithoutAPIKeys` is the behavioural cover (not run by X2b).
7. **Code under test is committed** at `2a2a346` (design rev 2.5 adopted, round 6); the run commit is a descendant containing the signed-off files (§2.6). RESULTS compares the recorded `client_go_sha256`/`provider_go_sha256`/`areas_go_sha256`/`records_go_sha256` with the `2a2a346` blobs, `scout_head` with the run commit, and the empty `git diff 2a2a346 <run commit> -- internal/ scripts/ third_party/clawpatch`. The collector records but does not refuse a dirty tree or another commit (no collector change was asked for; a refusal would be a collector change with a new pinned diff). Round-2 nit 5 (`math.ceil(0.04*250) = 10`; `C.wilson(6,126)[1] = 0.1000017 > 0.10 >= C.wilson(6,127)[1] = 0.09924`) was confirmed by execution before the text was frozen.
8. **No margin guard added.** X2's one near-edge result (0.0035) suggests one, but a new gate would diverge from X2's signed decision rule; margin, LOTO and non-contiguity are reported and must be stated in any design proposal (§4).
9. **Labellers unchanged** (claude default, codex default with `--ignore-user-config`, sonnet adjudicator); B's model is reported, not assumed; the same-family caveat remains and the same-model caveat applies if B serves `gpt-6-luna` (§6).
