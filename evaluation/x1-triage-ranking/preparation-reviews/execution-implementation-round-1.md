- **A. Narrow admission plus resolution guard (recommended).**
  - For: it keeps the single signed PATH mechanism (parents of `runtime.executables`) and adds only three closure-attested pins. - **B. A per-run private `bin/` directory of symlinks to exactly the three pins (the peer's preference).**

  - Against: a second PATH source, and `go` relies on symlink resolution to find GOROOT [INFERENCE: `cmd/go` follows the symlink, but that has never been run here]. If it failed, Clawpatch would silently fall back.
  - This is the fallback if round 2 rejects `/usr/bin` exposure.

- **D. Fix it in runtime generation only.** Impossible: `validate_runtime` (`:54–55`) rejects the needed rows.
- **E. Rebuild the frontend under a journal.** Rejected: no signed build procedure exists, it would be another `-r2` Go command or would produce a different binary, and it would not cure the breach.
- **F. Add only `git` and `sandbox-exec`, and accept Clawpatch's fallback for `go`.** Rejected: it contradicts the signed residual text naming the `go list` children, and it changes the mapping path the design describes.
